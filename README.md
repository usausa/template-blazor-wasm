# Template project for Blazor WebAssembly

[Template](https://usausa.github.io/template/) project for Blazor WebAssembly.

# ✅ Implement

| Category | Feature |
| --- | --- |
| UI | Blazor WebAssembly (ASP.NET Core hosted) / Fluent UI Blazor / Data grid (server paging, sorting) / Dialogs (edit, confirm) / Toast notifications / Error boundary |
| API | Minimal API (`/api`) / OpenAPI (Swagger UI, ReDoc) / API client generation (NSwag) / Shared contracts / Validation / ProblemDetails |
| Auth | JWT / Refresh token (rotation) / Auto refresh on 401 / Role policy |
| Data | SQLite (Smart.Data.Accessor) / Paging, sorting, and search / File storage API |
| HTTP | Compression (Brotli, Gzip) / Security headers / Forwarded headers |
| Observability | Serilog / HTTP log / W3C log / SQL profiler (MiniDataProfiler) / OpenTelemetry (OTLP, Prometheus) / Health checks |
| Operation | Feature flags / Windows service / systemd / Aspire AppHost |
| Test | Unit (xUnit v3, bUnit) / Integration (WebApplicationFactory) / E2E (Playwright) |
